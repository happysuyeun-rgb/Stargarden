# Stargarden 코드 검토 반영 작업

코드 검토(2026-10-15)에서 나온 문제를 아래 순서대로 고쳐줘. **단계마다 따로 커밋**하고, 각 단계의 "완료 기준"을 확인한 뒤 다음 단계로 넘어가.

## 지켜야 할 규칙

- `supabase/migrations/001~007`은 수정하지 마. DB 변경은 새 파일 `008_*.sql`로만 해.
- 마이그레이션은 다시 실행해도 오류가 없어야 해. `CREATE POLICY IF NOT EXISTS`는 PostgreSQL이 지원하지 않으니 `drop ... if exists` 후 `create`를 써.
- 날짜 판단은 전부 KST 기준. `src/lib/datetime.ts`의 `getKSTDateString()`을 써.
- 화면 문구에 "시들었어요", "놓쳤어요", "사라져요" 같은 표현은 쓰지 마 (압박 없는 힐링 원칙).
- 수치는 `src/constants/game.ts` 상수를 써. 숫자를 코드에 직접 쓰지 마.

## 1단계. 일일 씨앗이 다음 날 다시 지급되도록 수정 🔴

**문제**: `src/stores/seedsStore.ts`의 `hasReceivedToday`가 날짜 없는 boolean이라, 한 번 `true`가 되면 다음 날에도 그대로야. `GardenPage.tsx` 125~132행은 `!hasReceivedToday`일 때만 씨앗을 주니까 2일차부터 씨앗이 안 나와.

**수정**:
1. `seedsStore`에 `lastReceivedDate: string | null`(KST `YYYY-MM-DD`)을 추가해.
2. `grantDailySeed`와 `markReceivedToday`는 `lastReceivedDate = getKSTDateString()`으로 저장해.
3. `hasReceivedToday` boolean은 없애고, 받았는지는 `lastReceivedDate === getKSTDateString()`으로 판단하는 헬퍼(예: `hasReceivedSeedToday()`)로 바꿔.
4. 날짜가 바뀌면 `todaySeed`도 비워.
5. zustand `persist`에 `version: 1`과 `migrate`를 추가해. 예전 데이터(`hasReceivedToday`만 있고 날짜가 없는 경우)는 `lastReceivedDate: null`로 바꿔서 오늘 씨앗을 받을 수 있게 해.
6. `GardenPage`는 정원을 켜 둔 채로 자정을 넘겨도 새 씨앗이 나오도록, 1분마다 또는 `visibilitychange` 때 KST 날짜를 다시 확인해.
7. `seedDevSession.ts`의 `useSeedsStore.setState({ hasReceivedToday: false, ... })`도 새 필드에 맞게 고쳐.

**완료 기준**: 씨앗을 받은 뒤 `lastReceivedDate`를 어제 날짜로 바꾸고 정원에 들어가면 새 씨앗이 지급돼.

## 2단계. 정원이 영구히 잠드는 문제 수정 🔴

**문제**: `GardenPage.tsx` 88~99행. 31일 만에 들어오면 잠듦을 적용하고 바로 `touchActive()`로 `lastActiveAt`을 갱신해. 깨어남 모달을 닫지 않고 새로고침하면 `wasLongAbsent`가 `false`가 되어 모달이 다시 안 뜨고, 식물은 계속 잠든 상태로 남아.

**수정**: `isGardenSleeping`이 `true`이면 `wasLongAbsent`와 상관없이 항상 깨어남 모달을 띄워.

```ts
if (wasLongAbsent && !isGardenSleeping) {
  applyGardenSleep(true)
  setGardenSleeping(true)
  setShowWakeModal(true)
} else if (isGardenSleeping) {
  setShowWakeModal(true)
}
```

**완료 기준**: 잠듦 상태에서 모달을 닫지 않고 새로고침해도 모달이 다시 뜨고, 확인하면 식물이 깨어나.

## 3단계. 깨어날 때 잠든 시간을 성장에서 빼기 🟡

**문제**: `gardenStore.ts`의 `applyGardenSleep(false)`가 `sleptAt`만 지우고 `plantedAt`은 그대로 둬. 그래서 깨우는 순간 잠든 시간이 한꺼번에 더해져(심은 지 10시간·잠든 지 40시간인 식물이 진행률 0.21에서 1.04로 바로 개화).

**수정**:
1. `applyGardenSleep(false)`에서 `sleptAt`이 있는 아직 안 핀 식물은 `plantedAt`을 잠든 시간(`now - sleptAt`)만큼 뒤로 미뤄.
2. `src/lib/growth.ts`의 `getRemainingHours`를 진행률 기반으로 바꿔서 잠든 동안 "남은 시간"이 줄어들지 않게 해. `computePlantProgress` 결과로 `(1 - progress) * requiredHours`를 계산하면 돼.
3. `useGardenTick.ts`에서 잠든 식물(`isSleeping`)은 개화 대기 대상에서 빼 (설계: 잠든 동안 개화 거부).
4. 30일 공백 동안 성장을 계속 반영할지는 기획 결정이 남아 있으니, 지금 동작(복귀 시점부터 동결)은 유지하고 `// TODO(기획): 30일 공백 기간 성장 반영 정책 확정` 주석만 남겨.

**완료 기준**: 잠들기 전 진행률과 깨운 직후 진행률이 같아.

## 4단계. 온보딩 검증, 라우트 가드, 웰컴 씨앗 🟡

### 4-1. 온보딩 (`src/features/auth/OnboardingPage.tsx`)
- 2단계의 다음 버튼은 `birthTimeUnknown || birthTime`일 때만 활성화해. 지금은 시간을 안 골라도 넘어가서 `birthTimeUnknown=false, birthTime=null`인 모순 데이터가 저장돼.
- 만 14세 미만이면 다음으로 넘어가지 못하게 막고 안내 문구를 보여줘. 나이는 KST 오늘 날짜 기준 만 나이로 계산해. 음력 입력은 우선 양력과 같은 방식으로 계산하고 `// TODO: 음력→양력 변환 후 계산` 주석을 남겨.
- 날짜 입력의 `max`를 `new Date().toISOString().slice(0, 10)`(UTC)에서 `getKSTDateString()`으로 바꿔. 지금은 KST 00~09시에 오늘 날짜를 고를 수 없어.

### 4-2. 라우트 가드 (`src/routes/index.tsx`)
- `RequireOnboarded` 컴포넌트를 만들어서 `AppLayout` 하위 라우트와 `/garden/insight`를 감싸.
- `isOnboarded`도 `isDevMode`도 아니면 `/`로 보내.

### 4-3. 웰컴 씨앗 (`src/stores/seedsStore.ts`)
- `grantWelcomeSeed(ohangType)`로 바꾸고, 해당 오행의 **일반(normal)** 씨앗 중 하나를 랜덤으로 줘. 지금은 항상 새싹풀(`SEED_IDS.woodNormal1`)이야.
- `GardenPage`에서는 `ohangType ?? 'wood'`를 넘겨.

**완료 기준**: 시간을 안 고르면 다음 버튼이 비활성화되고, 2015년생 생일로는 가입이 막히고, 온보딩 전에 `/garden`에 직접 들어가면 `/`로 이동하고, 웰컴 씨앗이 내 오행의 씨앗으로 나와.

## 5단계. 008 마이그레이션 — DB 보조 제약 🟡

`supabase/migrations/008_integrity_constraints.sql`을 만들어. 다시 실행해도 오류가 없어야 해.

```sql
-- 같은 씨앗을 두 칸에 심지 못하게
alter table plants drop constraint if exists plants_user_seed_unique;
alter table plants add constraint plants_user_seed_unique unique (user_seed_id);

-- 슬롯 범위 (GARDEN_MAX_SLOTS = 12)
alter table plants drop constraint if exists plants_slot_index_range;
alter table plants add constraint plants_slot_index_range check (slot_index >= 0 and slot_index < 12);

-- 정원 슬롯 수 범위 (GARDEN_START_SLOTS 6 ~ GARDEN_MAX_SLOTS 12)
alter table profiles drop constraint if exists profiles_garden_slots_range;
alter table profiles add constraint profiles_garden_slots_range check (garden_slots between 6 and 12);

-- 가입 트리거가 profiles를 만들므로 클라이언트 insert 정책은 불필요
drop policy if exists "profiles_insert_own" on profiles;

-- notification_settings.updated_at 자동 갱신
drop trigger if exists trg_notification_settings_updated on notification_settings;
create trigger trg_notification_settings_updated before update on notification_settings
  for each row execute function set_updated_at();
```

**완료 기준**: 001~008을 빈 DB에 순서대로 적용해도, 008을 두 번 실행해도 오류가 없어.

## 6단계. Edge Function과 기타 정리 🟢

1. **`supabase/functions/send-push/index.ts`**: 지금은 `x-cron-secret` 헤더가 있는지만 확인해. `Deno.env.get('CRON_SECRET')`과 값이 같은지 비교하고, 환경변수가 없거나 값이 다르면 401을 반환해.
2. **`src/constants/seeds.ts` `getTodayEnergy`**: 기기 시간대의 요일(`getDay()`)을 써서 해외 사용자는 날짜가 어긋나고, 水·木이 주 2회라 분포도 치우쳐 있어. KST 날짜 기준으로 5개 오행을 균등하게 순환하도록 바꾸고 `// TODO: 만세력 일진 기반으로 교체` 주석을 남겨.
3. **`pickDailySeed`**: `0.15`를 직접 쓰지 말고 `RARE_PROBABILITY`를 써.
4. **`DEV_USER_ID`**: `'00000000-0000-0000-0000-dev00000001'`은 유효한 UUID가 아니야. `seedDevSession.ts`와 `authStore.ts` 모두 `'00000000-0000-0000-0000-00000000de01'`처럼 16진수로만 된 값으로 바꿔.
5. **번들 크기**: JS 번들이 528KB 단일 청크야. `SoundMixer`와 Tone.js를 쓰는 부분을 `React.lazy` / 동적 `import()`로 분리해서 첫 화면 로딩에서 빼.
