## 4단계. 잠듦 제거 → 복귀 연출 (D2)

잠듦은 이제 정원 상태가 아니야. 오래 비웠다 왔을 때 반겨주는 연출일 뿐이야.

1. **제거**
   - `gardenStore`: `applyGardenSleep`, `GardenPlant.isSleeping`, `GardenPlant.sleptAt`
   - `authStore`: `isGardenSleeping`, `setGardenSleeping`
   - `lib/growth.ts`: `isSleeping`, `sleptAt` 인자
   - `lib/careActions.ts`: `canWaterToday`, `canTapStarlight`의 잠듦 검사
   - `PlantCarePopover`: "잠든 동안은 성장과 돌보기가 멈춰요" 문구
   - 정원 슬롯의 💤 표시, `garden__slot--sleeping` 스타일
   - `lib/sleep.ts`의 `shouldGardenSleep`, `resolveWakeOnMount`
2. **바꾸기**
   - `WakeUpModal` → `ReturnGreetingModal`로 이름 변경
   - 문구: "오랜만이에요. 정원이 기다리고 있었어요"
   - 조건: `daysSinceActive(lastActiveAt) >= RETURN_GREETING_DAYS`일 때 정원 진입 시 한 번
   - 닫으면 끝. 아무 상태도 바꾸지 않음. 닫지 않고 새로고침해서 다시 안 나와도 괜찮음
   - 모달을 닫은 뒤 그동안 100%가 된 꽃들의 개화 모달을 하나씩 순서대로 보여줘 (`useGardenTick` 기존 흐름)
3. **저장 데이터 정리**: `gardenStore`, `authStore`의 persist `version`을 올리고 `migrate`에서 `isSleeping`, `sleptAt`, `isGardenSleeping`을 지워.
4. **테스트 교체**: `regression.test.ts`의 "잠듦" 테스트를 지우고 아래로 바꿔 (게임규칙서 G17~G19).
   - 8일 만에 접속 → 복귀 연출 표시, 물주기 가능
   - 6일 만에 접속 → 복귀 연출 없음
   - 오래 비운 동안 지난 시간이 성장에 모두 반영됨 (동결 없음)

**완료 기준**: `grep -rn "isSleeping\|sleptAt\|isGardenSleeping\|applyGardenSleep\|WakeUpModal" src` 결과 없음. 테스트 통과.

## 5단계. 온실 (D1) — 로컬 모드

서버 연동 전이라 지금은 스토어에서만 동작하게 만들어. 이후 서버 전환 때 같은 자리에서 `move-to-greenhouse`, `move-to-garden`을 호출하면 돼 (API명세서 v1.1 §3.4).

1. **데이터**
   - `GardenPlant`에 `location: 'garden' | 'greenhouse'` 추가, `slotIndex: number | null`
   - 기존 저장 데이터는 persist `migrate`에서 `location: 'garden'`으로
   - `gardenStore`에 `moveToGreenhouse(plantId)`, `moveToGarden(plantId, slotIndex)` 추가
   - 규칙: 핀 꽃만 온실로. 온실로 가면 `slotIndex = null`. 꺼낼 때는 빈 칸만
2. **정원 화면**
   - 정원 그리드는 `location === 'garden'`인 식물만 그려
   - 핀 꽃의 돌보기 팝오버에 **[온실로 옮기기]** 버튼
   - 정원 화면에 **온실** 버튼 (씨앗 주머니 버튼 옆). 누르면 바텀시트로 온실 목록
3. **온실 바텀시트**
   - 옮긴 꽃 목록: 이름, 오행 뱃지, 개화일, 소리 듣기 버튼
   - 꽃을 누르면 [정원으로 꺼내기] → 빈 칸 선택 모드 (심기와 같은 방식)
   - 빈 상태: "꽃이 피면 온실로 옮길 수 있어요"
4. **정원이 가득 찼을 때** (에러케이스정의서 v1.1 §3.6)
   - 씨앗을 심으려는데 빈 칸이 없으면: "정원이 가득해요. 온실로 옮길 꽃을 골라볼까요?" + [꽃 고르기] [주머니에 보관]
   - [꽃 고르기]: 핀 꽃만 강조되고, 누르면 온실로 옮긴 뒤 그 칸에 바로 심기
   - 핀 꽃이 없으면: "꽃이 피면 온실로 옮길 수 있어요" 안내 후 주머니에 보관
   - 지금 쓰는 `TOAST.gardenFull`("정원이 가득해요. 씨앗 주머니에 보관할게요")은 위 흐름으로 바꿔
5. **토스트 문구**: "온실로 옮겼어요. 소리는 그대로 들을 수 있어요" / "정원으로 다시 데려왔어요"

**완료 기준**: 6칸을 모두 핀 꽃으로 채운 뒤 새 씨앗을 심을 수 있음 (꽃 고르기 → 온실 → 그 칸에 심기). 온실로 옮긴 꽃을 다시 정원으로 꺼낼 수 있음.

## 6단계. 소리를 도감 기준으로 (D1)

지금 `useGardenSound(plants)`는 정원에 있는 핀 꽃으로 채널을 만들어. 온실로 옮기면 소리가 사라지니까 기준을 바꿔야 해.

1. 채널 목록은 **도감(`collectionStore.entries`)에 있는 종의 소리**로 만들어. 같은 소리를 쓰는 종이 여러 개면 채널은 하나.
2. 정원·온실 위치와 상관없이 해금한 소리는 믹서에 항상 보여.
3. 채널이 8개(`SOUND_MAX_CHANNELS`)를 넘으면 사용자가 켠 것만 재생하고, 믹서에 "한 번에 8개의 소리까지 흐를 수 있어요" 안내.
4. 돌보기 팝오버의 개별 볼륨 조절은 그 꽃의 소리 채널을 조절하는 것으로 유지.

**완료 기준**: 핀 꽃을 온실로 옮겨도 믹서에 그 소리가 남고 재생됨.

## 7단계. 희귀 천장(D5)과 개화 횟수(D3) — 로컬 모드

1. **희귀 천장**
   - `seedsStore`에 `daysSinceRare: number` (persist)
   - `pickDailySeed(energyCode, forceRare)`: `daysSinceRare >= RARE_PITY_DAYS`면 희귀 확정
   - 일일 씨앗이 희귀면 0, 일반이면 +1. 웰컴 씨앗은 영향 없음
2. **개화 횟수**
   - `CollectionEntry`에 `bloomCount: number` (기존 데이터는 `migrate`에서 1)
   - `registerBloom`이 이미 있는 종이면 `bloomCount + 1`
   - 개화 모달 문구: 처음이면 "도감에 새로 기록되었어요", 아니면 "{종 이름}이(가) {N}번째로 피었어요"
   - 도감 상세(`PlantDetailPage`)에 "N번 피웠어요"
3. **테스트 추가**
   - 일일 씨앗 10번 연속 일반이면 11번째는 희귀 (G15)
   - 같은 종 두 번 개화 → `bloomCount` 2
   - 핀 꽃 온실로 옮김 → 칸이 비고 도감·소리 유지 (G16)

**완료 기준**: `npm run test` 통과.
