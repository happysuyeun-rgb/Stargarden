## 1. 핵심 루프의 막다른 길 (최우선)

### 1-1. 정원이 7칸 근처에서 꽉 차고 더 늘어나지 않음

개화한 식물이 그 뒤에 어떻게 되는지 정의되어 있지 않다. 뽑기·옮기기·수확 기능이 없어 핀 식물이 칸을 계속 차지한다.

- 칸은 개화 5회마다 1칸씩 늘어남 (시작 6칸)
- 6칸을 모두 피우면 개화 6회 → 7칸
- 1칸을 더 심어 피우면 개화 7회 → 7칸이 모두 참
- 8칸이 되려면 개화 10회가 필요하지만 빈 칸이 없음
- 이후 매일 받는 씨앗은 주머니에 쌓이기만 함

**결정 필요**
- 개화한 식물의 다음 상태: 정원에 계속 둠 / 도감·화분으로 보냄 / 수확
- 사운드를 정원 칸에 묶을지, 도감 수집에 묶을지 (식물을 치우면 소리도 사라지는지)
- 같은 종을 다시 피웠을 때의 보상 (현재 도감 중복 등록 불가로 의미 없음)
- 씨앗 주머니 보관 개수 상한

### 1-2. 잠듦 기능이 실제로는 의미가 없음

식물은 최대 96시간이면 피는데, 잠듦은 30일 공백 후에 시작된다. 잠드는 시점에는 이미 모두 피어 있어 "잠든 동안 성장 정지·개화 거부" 정책과 맞지 않는다.

**결정 필요 (택1)**
- A안: 마지막 접속 후 일정 시간(예: 3일)까지만 성장하고 이후 정지
- B안: 잠듦을 성장과 분리하고 "오랜만에 돌아왔을 때의 맞이 연출"로만 사용

## 2. 사주 산출 규칙 미정의

현재 문서에는 "만세력으로 산출"만 있고 규칙이 없다. 코드의 오행 산출은 생일 끝자리를 쓰는 임시 방식이다. 아래를 기획에서 확정해야 정식 로직으로 교체할 수 있다.

| 항목 | 정해야 할 내용 |
|---|---|
| 내 기질 | 일간(日干) 기준인지 |
| 오늘의 에너지 | 일진의 천간인지 지지인지 |
| 자시 경계 | 23~01시 출생의 날짜 처리 (야자시 / 조자시) |
| 음력 | 윤달 처리 방식 |
| 시간 보정 | 한국 표준시 경도 보정(약 30분), 과거 서머타임 연도 반영 여부 |
| 시간 모름 | 산출 방식과 결과 화면 안내 문구 |

## 3. 동의·법무 화면 공백

- **수집 동의 방식**: 로그인 화면이 "시작하면 동의하게 됩니다"라는 묵시적 동의다. 생년월일과 태어난 시간을 수집하므로 수집 항목·목적·보관 기간을 알리고 명시적으로 동의받는 화면이 필요해 보인다. 출시 전 전문가 확인 권장.
- **동의 이력 저장**: `legal_consents` 테이블 미설계. 우리사이와 공통 모듈화 검토도 미결.
- **만 14세 미만 차단**: 정책(NFR-04)에만 있고 화면 정의 없음.
- **계정 삭제**: 삭제 시 구독 처리, 데이터 보관 기간 미정의.
- **AI 해석 면책 문구**: "참고용 콘텐츠" 안내의 위치 미정의.
- **결제 정책**: 웹 결제 구독을 앱에서도 인정하는 구조이므로 앱스토어의 외부 결제 안내 규정 확인 필요.
