## 1. 원칙

### 1.1 문구 톤

힐링 게임이므로 오류 상황에서도 사용자를 탓하거나 불안하게 만들지 않는다.

| 쓰지 않음 | 대신 |
|---|---|
| 실패했습니다, 오류가 발생했습니다 | ~하지 못했어요, 잠시 후 다시 해볼까요 |
| 시들었어요, 놓쳤어요, 사라져요 | 잠들었어요, 기다리고 있어요 |
| 잘못된 입력입니다 | ~을 확인해 주세요 |
| 에러 코드·영문 노출 (`500`, `NOT_FOUND`) | 화면에는 한국어 문구만 |

- 원인이 사용자에게 있지 않으면 "다시 시도" 행동을 함께 준다.
- 문구는 `src/constants/errors.ts` 한곳에서 관리한다 (§7 문구 사전).

### 1.2 표시 방식 4종

| 방식 | 언제 | 사라지는 조건 |
|---|---|---|
| **토스트** | 행동 결과를 짧게 알릴 때. 화면을 막지 않음 | 3초 후 자동 |
| **인라인** | 입력 필드 검증, 버튼 아래 보조 문구 | 입력을 고치면 |
| **모달** | 사용자가 확인하거나 선택해야 할 때 | 버튼을 누를 때 |
| **상태 화면** | 화면 전체 데이터를 못 불러왔을 때 (`ErrorState`, `LoadingState`) | 다시 시도 성공 시 |

한 번에 토스트는 하나만 보인다. 같은 문구가 3초 안에 다시 오면 무시한다.

### 1.3 먼저 반영하고, 실패하면 되돌린다

물주기·별빛·심기는 버튼을 누르는 즉시 화면에 반영한다 (기다리는 느낌을 주지 않기 위해). 서버 응답이 오면:

- **성공**: 응답의 `plant`로 스토어를 덮어쓴다 (서버 값이 기준)
- **실패**: 누르기 전 상태로 되돌리고, 필요하면 **정원 다시 불러오기**(`refreshGarden()`)를 실행한다

`refreshGarden()`은 클라이언트에서 `plants`, `user_seeds`, `profiles`를 SELECT해 스토어를 서버 값으로 맞추는 함수다 (RLS에서 본인 SELECT는 허용됨). 이 문서에서 "동기화"는 이 함수를 뜻한다.

개화 확정(`confirm-bloom`)은 예외다. **서버가 확정한 뒤에만** 개화 모달을 띄운다. 먼저 띄웠다가 취소하면 경험이 크게 깨지기 때문이다.

### 1.4 재시도 정책

| 에러 | 자동 재시도 | 비고 |
|---|---|---|
| `NETWORK_ERROR`, `INTERNAL_ERROR` (5xx) | 최대 2회, 1초 → 3초 간격 | 아래 표의 "자동 재시도 안 함" 함수는 제외 |
| `RATE_LIMITED` (429) | 1회, 5초 후 | |
| 4xx 나머지 | 하지 않음 | 요청 자체가 맞지 않으므로 다시 보내도 같음 |

**자동 재시도 안 함**: `tap-starlight`, `verify-purchase`, `delete-account`
- `tap-starlight`: 응답만 늦게 온 경우 서버에는 이미 반영됐을 수 있어 다시 보내면 탭이 두 번 들어간다. 실패하면 모아둔 탭을 버리고 동기화한다.
- 결제·계정 삭제: 사용자가 직접 다시 누르게 한다.

`plant-seed`는 재시도해도 안전하다. 응답이 늦어 다시 보낸 경우 `SEED_ALREADY_PLANTED` 또는 `SLOT_OCCUPIED`가 오는데, 이때 동기화해서 그 씨앗이 이미 그 칸에 심겨 있으면 **성공으로 처리**한다.

### 1.5 로그

- 모든 Edge Function 오류는 함수 로그에 `function`, `code`, `user_id`, 소요 시간을 남긴다.
- **생년월일·태어난 시간은 로그에 남기지 않는다.**
- 클라이언트는 개발 중 `console.warn`으로만 남긴다. 운영용 오류 수집 도구는 출시 전에 정한다.

## 2. 공통 에러 (모든 화면)

| code | 상황 | 사용자에게 보이는 것 | 화면·데이터 처리 |
|---|---|---|---|
| `NETWORK_ERROR` | 응답 없음, 연결 끊김 | 토스트 "연결이 잠시 끊겼어요" | 자동 재시도(§1.4) 후에도 실패하면 되돌리기. 오프라인이면 상단 `OfflineBanner` |
| `UNAUTHORIZED` | 로그인 만료 | (1차) 표시 없음 → (2차) 모달 "다시 로그인해 주세요" | supabase-js 토큰 갱신을 1회 시도하고 요청을 다시 보냄. 그래도 401이면 모달 후 로그인 화면으로. **정원 스토어는 지우지 않음** |
| `FORBIDDEN`, `NOT_FOUND` | 다른 기기에서 바뀐 데이터 등 | 토스트 "정원을 새로 불러왔어요" | 동기화 |
| `NOT_ONBOARDED` | 온보딩 안 끝난 상태로 정원 기능 호출 | 표시 없음 | `/onboarding`으로 이동 |
| `GARDEN_SLEEPING` | 정원이 잠든 상태로 돌보기 | 깨어남 모달 | 모달 표시. 되돌리기 |
| `RATE_LIMITED` | 너무 자주 호출 | 토스트 "조금 천천히 해볼까요" | §1.4 |
| `INTERNAL_ERROR` | 서버 오류 | 토스트 "별빛이 잠시 흐려졌어요. 잠시 후 다시 해볼까요" | 자동 재시도 후 되돌리기 |
| `NOT_IMPLEMENTED` | 아직 스텁인 함수 (개발 중) | 개발 모드: 토스트 "아직 준비 중인 기능이에요" / 운영: 발생하면 안 됨 | 로컬 모드로 처리 |
| `SUPABASE_NOT_CONFIGURED` | 환경변수 없음 (목업 실행) | 표시 없음 | 로컬 스토어만으로 동작 (현재 목업 방식) |

## 3. 기능별 분기

### 3.1 온보딩 — `complete-onboarding`

> ⚠ **API 명세서 v1.0 §3.1 호출 시점 수정 필요**: 명세서는 "기질 결과 화면 → 정원 진입 직전"에 호출하도록 돼 있다. 그런데 기질 결과 화면은 클라이언트가 계산한 오행을 보여주므로, 사주 산출 규칙이 바뀌면 화면에 보인 기질과 서버에 저장된 기질이 달라진다. **2단계(태어난 시간) 완료 버튼을 누를 때 호출하고, 결과 화면은 서버 응답의 `ohang_type`으로 보여주도록** 바꾼다.

| 상황 | code | 보이는 것 | 처리 |
|---|---|---|---|
| 날짜 형식 오류, 미래 날짜 | `VALIDATION_ERROR` | 인라인 "생년월일을 확인해 주세요" | 1단계 날짜 필드로 이동 |
| 시간 미선택 | (클라이언트에서 막음) | 다음 버튼 비활성 | 서버까지 가지 않음 |
| 만 14세 미만 | `AGE_RESTRICTED` | 안내 화면 (§3.1.1) | 입력값을 스토어에 저장하지 않음 |
| 이미 온보딩 완료 | `ALREADY_ONBOARDED` | 표시 없음 | 동기화 후 `/garden` |
| 연결 실패 | `NETWORK_ERROR` | 버튼 아래 인라인 "연결이 잠시 끊겼어요" + 다시 시도 | 입력값 유지, 버튼 로딩 해제 |

**호출 중**: 버튼에 로딩 표시, 중복 클릭 막기. 3초 넘으면 "별을 읽는 중이에요" 문구.

#### 3.1.1 만 14세 미만 안내 화면 (신규)
- 문구: "별의 정원은 만 14세부터 함께할 수 있어요. 그때 다시 만나요."
- 버튼: "처음으로" → 로그인 화면. 계정은 만들어졌으므로 로그아웃 처리한다.
- 화면정의서에 추가 필요 (§8).

### 3.3 접속 기록 — `touch-active`

**이 함수의 실패는 사용자에게 보이지 않는다.** 앱 사용을 막지 않는다.

| 상황 | 처리 |
|---|---|
| 성공, `needs_wake_modal = true` | 깨어남 모달 표시 |
| 성공, `needs_wake_modal = false` | 아무것도 안 함 |
| 실패 (모든 code) | 마지막으로 알던 상태로 그대로 진행. 다음 앱 복귀 때 다시 호출 |

**잠듦 고착 방지**: 스토어의 잠듦 상태가 `true`이면 서버 응답과 상관없이 깨어남 모달을 띄운다 (클라이언트 버그 2-2 재발 방지).

### 3.8 별빛 쬐기 — `tap-starlight`

**탭**: 화면에 바로 반짝임과 게이지를 반영하고, 탭 수를 모아 둔다. 마지막 탭 후 1초 또는 팝오버를 닫을 때 한 번에 보낸다.

| 상황 | 보이는 것 | 처리 |
|---|---|---|
| 성공, `cap_reached: false` | 없음 (탭 연출만) | 응답으로 덮어쓰기 |
| 성공, `cap_reached: true` | 버튼 아래 "오늘 별빛은 충분히 쬐었어요" | 버튼 비활성. 받아들여지지 않은 탭만큼 게이지를 응답 값으로 맞춤 |
| `GARDEN_SLEEPING` | 깨어남 모달 | 모아둔 탭 버리기 + 되돌리기 |
| `PLANT_ALREADY_BLOOMED` | 없음 | 모아둔 탭 버리기 + 동기화 |
| 연결 실패 | **표시 없음** | 재시도하지 않음(§1.4). 모아둔 탭 버리고 동기화 |

별빛은 작은 보너스라 실패를 알리지 않는다. 연출은 그대로 즐기고, 게이지만 서버 값으로 조용히 맞춘다.

### 3.9 개화 — `confirm-bloom`

**흐름**: 클라이언트 계산 진행률이 100%가 되면 식물을 "곧 피어나요" 상태로 바꾸고 `confirm-bloom` 호출 → **성공 응답 후에** 개화 모달과 사운드 재생.

| 상황 | code | 보이는 것 | 처리 |
|---|---|---|---|
| 성공 | — | 개화 모달, 소리 재생. `is_new_collection`이면 "도감에 등록되었어요", `slot_unlocked`면 "정원이 한 칸 넓어졌어요" | 응답으로 식물·도감·칸 수 갱신 |
| `already_bloomed: true` | — | 모달 없음 | 개화 상태로 표시, 도감 동기화 (다른 기기에서 확정한 경우) |
| 아직 덜 자람 | `NOT_READY` | 없음. "곧 피어나요" 유지 | `remaining_hours` 뒤에 다시 호출 (클라이언트 시계가 빠른 경우) |
| 잠든 상태 | `GARDEN_SLEEPING` | 깨어남 모달 | 깨어난 뒤 다시 확인 |
| 연결 실패 | `NETWORK_ERROR` | 없음. "곧 피어나요" 유지 | 1분 뒤, 앱 복귀 때 다시 호출 |

여러 식물이 동시에 100%가 되면 하나씩 순서대로 확정하고 모달도 하나씩 띄운다.

## 4. 클라이언트 전용 상황

서버를 거치지 않지만 사용자가 겪는 상황이다.

| # | 상황 | 보이는 것 | 처리 |
|---|---|---|---|
| 4-1 | **오프라인** | 상단 배너 "별빛이 잠시 흐려졌어요. 연결되면 다시 이어갈게요" | 정원 보기·소리 재생은 그대로. 돌보기 버튼은 누르면 토스트 "연결되면 다시 해볼까요"(되돌리기 없이 아예 반영 안 함). 다시 연결되면 `touch-active` + 동기화 |
| 4-2 | **소리 재생이 막힘** (브라우저 자동재생 정책으로 `Tone.start()` 실패) | 사운드 버튼 위 말풍선 "소리를 켜려면 한 번 눌러주세요" | 사용자의 다음 탭에서 `Tone.start()` 재시도. 현재 `soundEngine.ts`의 `ensureStarted()`에 실패 처리가 없어 추가 필요 |
| 4-3 | **사운드 하나를 못 불러옴** | 없음 | 그 채널만 빼고 나머지는 계속 재생 |
| 4-4 | **동시 재생 8채널 초과** | 믹서에 "가장 최근에 핀 8개의 소리가 흐르고 있어요" | 개화 시각 최신순 8개만 재생 (기능정의서 FR-D01) |
| 4-5 | **자정을 넘김** (앱을 켜 둔 채) | 없음 | 오늘의 씨앗 다시 확인, 물주기 버튼 다시 활성 (Cursor작업지시 1단계) |
| 4-6 | **앱이 백그라운드에서 돌아옴** | 없음 | `touch-active` + 동기화 (5분 이상 지났을 때만) |
| 4-7 | **기기 시계가 틀림** | 없음 | 게이지는 기기 시계로 그리지만, 모든 서버 응답으로 덮어씀. 개화는 서버가 판단 (`NOT_READY`) |
| 4-8 | **브라우저 저장소를 못 씀** (사생활 보호 모드 등) | 없음 | 메모리로 동작. Supabase 연동 후에는 서버에서 다시 불러오므로 문제 없음 |
| 4-9 | **여러 기기에서 동시에 사용** | 해당 동작의 에러 처리를 따름 | 서버 값이 기준. 앱 복귀 때 동기화 |
| 4-10 | **온보딩 전 정원 주소로 직접 접근** | 없음 | 라우트 가드로 `/` 이동 (Cursor작업지시 4-2) |
| 4-11 | **동의 전 온보딩 접근** | 없음 | `/consent`로 이동 |
| 4-12 | **이미 온보딩한 사용자가 `/onboarding` 접근** | 없음 | `/garden`으로 이동. 생년월일시 변경은 프로필 수정에서만 |
| 4-13 | **로그인(OAuth) 실패·취소** | 토스트 "별이 잠시 흐려졌어요. 다시 시도해주세요" (기존 `TOAST.oauthFailed`) | 로그인 화면 유지 |
