## 1. 한 줄 요약

웹 프론트엔드 목업과 2026-10-15 코드 검토의 클라이언트 수정은 반영되어 있습니다.  
Supabase 실연동, OAuth, 결제, 푸시 구현, 실제 에셋, 배포는 **사용자(서아 스튜디오) 측 인프라·콘텐츠 작업**이 필요합니다.

Edge Function 14종은 모두 501 스텁입니다. **007·008은 Edge Function 구현 후 운영 DB에 적용**합니다. 007은 클라이언트 쓰기를 막으므로, 함수 없이 적용하면 정원 데이터를 쓸 수 없습니다.

## 6. 프론트엔드 구조

```
src/
├── components/   TabBar, BottomSheet, Toast, DevModeBadge,
│                 LoadingState, ErrorState, OfflineBanner
├── features/     auth(스플래시·로그인·동의·온보딩), garden, sound, collection, my
├── stores/       auth, garden, seeds, sound, collection, tutorial, toast
├── lib/          growth, ohang, careActions, soundEngine, sleep, datetime, supabase
├── constants/    game, seeds, sounds, strings, legal
└── hooks/        useGardenSound
```

로컬 실행: `npm install` 후 `npm run dev` → http://localhost:5173/  
개발자 모드를 끄려면 `.env`에 `VITE_DEV_BYPASS_AUTH=false`. Supabase 키 없이도 Zustand persist로 동작합니다.

## 7. 알려진 제한

| 항목 | 현재 상태 |
|---|---|
| 오행 산출 | 생일 스텁. 만세력 미적용. 음력은 양력과 같은 계산 |

| 약관 본문 | 자리표시자. 법무 검토본 전 |
| 구독/결제/알림/AI 해석 | 미구현 또는 정적 폴백 |
| 동의 기록 | 브라우저 `authStore`만. 서버 테이블 없음 |
