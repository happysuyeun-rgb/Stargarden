## 1. 잠듦과 성장

잠든 동안의 성장을 어떻게 반영할지는 기획에서 아직 결정되지 않았다.

- **보류**: 깨어날 때 잠든 시간을 성장에서 빼는 처리(성장 동결)는 진행하지 않는다.
- **유지**: 깨어남 모달을 닫지 않고 새로고침하면 정원이 계속 잠드는 문제는 고친다. 잠든 상태이면 접속 시각과 관계없이 깨어남 모달을 다시 보여 준다.

30일 공백 기간의 성장 반영 방식은 정책이 정해진 뒤에 구현한다.

## 2. 동의 화면

로그인 다음, 온보딩 전에 `/consent` 화면을 둔다.

| 항목 | 구분 |
|---|---|
| 서비스 이용약관 | 필수 |
| 개인정보 수집·이용 | 필수 |
| 마케팅 정보 수신 | 선택 |
| 전체 동의 | 위 항목을 한 번에 선택 |

개인정보 수집·이용 안내:

- 수집 항목: 생년월일, 태어난 시간, 양력/음력
- 목적: 오행 기질 산출과 맞춤 콘텐츠 제공
- 보관 기간: 회원 탈퇴 시까지

각 항목에는 보기 버튼을 두고, 누르면 바텀시트로 약관 본문을 보여 준다. 본문은 `src/constants/legal.ts`의 자리표시자이며, 버전 문자열은 `2026-10-15`이다.

필수 항목 두 개를 모두 체크해야 다음 버튼이 활성화된다.

동의 결과는 클라이언트 `authStore`에 아래 형태로 저장한다. DB 테이블은 만들지 않는다.

```ts
{ termsVersion, privacyVersion, marketingOptIn, agreedAt }
```

로그인 화면의 "시작하면 서비스 이용약관 및 개인정보처리방침에 동의하게 됩니다." 문구는 두지 않는다. 동의는 이 화면에서만 받는다.

동의 기록이 없으면 `/onboarding`과 정원 화면에 들어갈 수 없다. 개발자 모드는 예외다.

화면 하단에 "AI가 만든 해석은 참고용 콘텐츠예요"를 한 줄 안내한다.

## 3. 공통 상태 표시

`src/components/`에 다음을 둔다.

| 컴포넌트 | 역할 |
|---|---|
| `LoadingState` | 불러오는 중 |
| `ErrorState` | 이어가지 못한 상태. 다시 시도 버튼 포함 |
| `OfflineBanner` | 오프라인 안내 |

`OfflineBanner`는 `navigator.onLine`과 `online` / `offline` 이벤트로 표시하고, 앱 상단에 전역으로 붙인다.

문구는 압박 없는 톤을 쓴다. 오프라인 예: "별빛이 잠시 흐려졌어요. 연결되면 다시 이어갈게요."

서버 호출이 없는 지금은 화면에 붙이는 것은 오프라인 배너뿐이다. 로딩과 오류 컴포넌트는 만들어 두고, 서버 연동 때 사용한다.
